# Planner

Mahmut's weekly planner — a PWA hosted on GitHub Pages, backed by Supabase, updated by Claude every morning at 6:00.

- App: `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, `icons/`
- Database schema: `supabase/schema.sql`
- Push dispatcher (Supabase Edge Function): `supabase/functions/push-dispatch/index.ts`

Install on iPhone: open the site in Safari → Share → Add to Home Screen → open it from the home screen → Settings → Enable notifications.
